# 500万的人生

一个完全由 AI 驱动的沉浸式人生模拟游戏。你可以用对话走完一笔意外之财的人生、从零开始白手起家、冲刺高考，也可以成为某个时代某个国家/势力的掌权者，改写在历史。

游戏需要连接 DeepSeek API（模型走官方 `chat/completions` 接口），AI 负责全部叙事与模拟。

---

## 快速开始

1. 用浏览器打开 `index.html`（双击即可，需要联网）；
2. 点击「开始游戏」；
3. 首次使用输入 DeepSeek API Key（保存在本机浏览器 `localStorage`，不会上传到第三方）；
4. 在游戏列表选择人生；
5. 按提示输入姓名（战争/高考类还需输入国家/学校）；
6. 开始游戏：可以直接打字，也可以点击 AI 给出的选项按钮。

> 获取 API Key：<https://platform.deepseek.com/api_keys>

## 玩法规则（AI 提示词内置）

- 每次行动后时间向前推进几天/几周/几个月；
- 回复采用固定结构（时间 / 资产或国家信息 / 情况）；
- 所有关键抉择由 AI 给出**具体选项按钮**（`[OPTION:]` 标记），禁止“继续”之类充数；
- 需要补充信息时 AI 必须询问（`[ASK:]` 标记），不得替玩家默认或编造；
- 危险/出格行为（自杀、赌博、作死等）AI 最多劝阻一轮，玩家再次坚持即放行；
- 数值一律阿拉伯数字：人口/军力为不带单位的精确数，财政带货币单位；
- 死亡由 AI 根据年龄、健康、病情、意外动态判定，不设固定寿命。

## 各模式结束条件

- 普通人生：角色死亡 → 游戏结束；
- 高考人生：高考（6 月 7-9 日）结束当场给出高考总分 → 游戏结束；中途死亡同样结束；
- 三国鼎立 / 大航海时代：个人死亡、被推翻下台/废黜/流亡，或国家/势力被灭 → 结束；**休战/议和/结盟不算结束**；
- 一战 / 二战：阵营整体覆灭/投降、签订全面和约或世界战争落幕 → 结束；个人亡国/下台/死亡也结束。

结束时会输出 `[GAME_OVER]`，弹出「查看人生总结」，展示人生跨度、事件时间线、成就与遗憾、最终资产/分数/财政。

## 界面与可视化

- **人生仪表盘**（右侧，小窗口自动变顶部横条）：时间与年份进度、人物（姓名/年龄/健康）、资产/现金或考试总分、走势图、时间轴；
- **战争仪表盘**：人口、军力、财政三条数据条（数值随回复更新）；
- **高考模式**：考试总分走势图 + 独立“最近总分/高考总分”卡片；
- **选项按钮**：AI 每轮给出可点击的具体选择；
- **待确认信息卡片**：AI 需要你补充信息时用 `[ASK:]` 询问；
- **人生总结页**：人物档案、Canvas 时间线（按真实时间比例、同日期去重）、关键事件、成就与遗憾（无序列表）、再来一次/返回主菜单。

## 技术备注

- 对话请求发送到 `https://api.deepseek.com/chat/completions`；
- 模型默认 `deepseek-v4-flash`，可在 Key 页切换 `deepseek-v4-pro`；
- 请求显式关闭思考模式（`thinking: disabled`），回复更快更省；
- API Key、模型选择保存在浏览器本地，刷新页面不丢失；
- AI 使用结构化标记与前端协作：
  - `[OPTION:]` 选项按钮
  - `[ASK:]` 待确认信息
  - `[STAT:]` 国家仪表盘数据（解析后隐藏）
  - `[SCORE:]` 高考总分
  - `[ACHIEVEMENT:]` / `[REGRET:]` 成就与遗憾
  - `[GAME_OVER]` 游戏结束
